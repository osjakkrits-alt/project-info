# Project Starter Template

A technology-neutral starting point for software projects. It provides a consistent repository layout, Git workflow, lightweight documentation, and reusable Codex prompts without prescribing a language, framework, or toolchain.

## Getting started

1. Create a repository from this template.
2. Replace project placeholders in this README and the files under `docs/`.
3. Copy `.env.example` to the environment file used by your chosen tools and fill values locally.
4. Select and customize a prompt from `docs/ai/codex/templates/` when using Codex.
5. Follow the workflow in `docs/workflow.md`.

## Repository structure

- `docs/`: roadmap, architecture, workflow, conventions, decisions, and project history.
- `docs/ai/codex/`: Codex usage notes, prompt library, and reusable prompts.
- `src/`: application or library source files selected by the project.
- `tests/`: automated tests and test documentation.
- `scripts/`: repeatable development and maintenance scripts.
