# Repository Instructions for Codex

## Purpose

Maintain this repository as a technology-neutral starter template. Do not introduce application-specific source code, dependencies, frameworks, or generated artifacts unless the task explicitly changes that scope.

## Before making changes

1. Inspect the repository tree, relevant documentation, and Git status.
2. Read instructions in the nearest applicable `AGENTS.md` file.
3. Identify existing conventions and validation commands before editing.
4. Keep the requested GitHub Issue / Sprint and pull-request workflow intact.

## Making changes

- Make the smallest coherent change that satisfies the request.
- Limit edits to files relevant to the task and preserve unrelated user changes.
- Keep documentation concise, reusable, and technology-neutral.
- Do not add secrets. Use explicit placeholders in examples.
- Update related documentation when behavior, architecture, workflow, or conventions change.

## Validation

- Run all available checks relevant to changed files, such as formatting, linting, tests, builds, and documentation checks.
- If no validation is configured, perform focused manual checks and state that automated validation was unavailable.
- Do not hide or bypass failures. Report every skipped, unavailable, or blocked check with the reason.

## Handoff

Summarize changed files and behavior, list validation performed and its result, and call out assumptions, risks, or blocked checks. Do not commit, push, or create a pull request unless explicitly requested.
