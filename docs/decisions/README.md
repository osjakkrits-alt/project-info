# Architecture Decision Records

Store significant, durable technical decisions in this directory. Create one Markdown file per decision using a sortable name such as `0001-select-runtime.md`.

## Suggested record

```markdown
# <Decision title>

- Status: Proposed | Accepted | Superseded | Deprecated
- Date: YYYY-MM-DD
- Owners: <people or team>

## Context
<Problem, constraints, and forces.>

## Decision
<Chosen approach.>

## Consequences
<Benefits, costs, risks, and follow-up work.>

## Alternatives considered
<Options and why they were not selected.>
```
