# Sales Status Flow

## วัตถุประสงค์และขอบเขต

กำหนดขั้นตอนขาย สถานะ ข้อมูลขั้นต่ำ และเงื่อนไขส่งต่องานสำหรับ Sales ใน [Project Information Lifecycle](../project-information-lifecycle.md) โดยใช้ Opportunity เป็นหน่วยติดตามงาน และอ้างอิงลูกค้าตาม [Customer Info](customer-info.md)

กติกานี้เป็นค่าเริ่มต้นสำหรับทีม โดยเฉพาะเกณฑ์ Won ให้ใช้หลักฐานการยอมรับข้อเสนอของลูกค้าเพื่อส่งต่อไป Contract / SOW ไม่ได้หมายความว่าสัญญาลงนามแล้วหรือเริ่ม Delivery ได้ทันที

## Stage และ Status

Stage ระบุว่างานอยู่ขั้นตอนไหน ส่วน Status ระบุว่างานยังดำเนินอยู่ พักไว้ หรือปิดแล้ว

ลำดับปกติ: **Lead / Opportunity → Discovery → Proposal & Estimate → Decision**

| Stage | วัตถุประสงค์ |
| --- | --- |
| Lead / Opportunity | รับความต้องการเบื้องต้น ระบุลูกค้า และมอบหมายผู้รับผิดชอบ |
| Discovery | ทำความเข้าใจปัญหา เป้าหมาย ขอบเขต และข้อจำกัด |
| Proposal & Estimate | ประเมินงาน จัดทำข้อเสนอ ส่งลูกค้า และเจรจา |
| Decision | ติดตามและบันทึกการตัดสินใจของลูกค้า |

| Status | ความหมาย | ใช้กับ Stage |
| --- | --- | --- |
| Open | กำลังดำเนินการ ต้องมีงานติดตามถัดไป | ทุก Stage |
| On hold | พักงานชั่วคราว ต้องมีเหตุผลและวันติดตามใหม่ | ทุก Stage |
| Won | ลูกค้ายอมรับข้อเสนอที่ระบุได้และพร้อมส่งต่อจัดทำ Contract / SOW | Decision เท่านั้น |
| Lost | ปิดโอกาสขายโดยไม่ได้รับงาน ต้องมีเหตุผล | ทุก Stage โดยคงขั้นตอนที่ปิดงานไว้ |

ตัวอย่าง: **Proposal & Estimate + On hold** หมายถึงพักงานระหว่างทำหรือเจรจาข้อเสนอ เมื่อกลับมาทำต่อให้เปลี่ยนเป็น Open และคง Stage เดิม

## ข้อมูลขั้นต่ำของ Opportunity

| ข้อมูล | ต้องมีเมื่อใด | รายละเอียด |
| --- | --- | --- |
| Opportunity ID | สร้างรายการ | รหัสงานไม่ซ้ำ |
| ชื่องาน | สร้างรายการ | ชื่อที่แยกงานนี้จากงานอื่นของลูกค้าได้ |
| Customer ID | สร้างรายการ | อ้างอิงลูกค้าหนึ่งราย |
| Opportunity owner | สร้างรายการ | ผู้รับผิดชอบติดตามงานขาย |
| ความต้องการเบื้องต้น | สร้างรายการ | สรุปปัญหาหรือสิ่งที่ลูกค้าสนใจ |
| Stage / Status | สร้างรายการ | เริ่มที่ Lead / Opportunity และ Open |
| กิจกรรมถัดไป ผู้รับผิดชอบ และวันครบกำหนด | ทุกงาน Open / On hold | งานที่ต้องทำต่อหรือการติดตามเพื่อกลับมาดำเนินงาน |
| ผู้ติดต่อและบทบาท | ก่อนเข้า Discovery | อ้างอิง Contact รวมถึงผู้ติดต่อหลักของงาน |
| ที่มาของโอกาสขาย | เมื่อทราบ | เช่น ลูกค้าเดิม การแนะนำ หรือการติดต่อเข้ามา |
| งบประมาณ มูลค่าคาดการณ์ และสกุลเงิน | เมื่อทราบ | แยกงบลูกค้าออกจากมูลค่าที่คาดว่าจะเสนอ ไม่ใช้ศูนย์แทนค่าที่ไม่ทราบ |
| วันที่คาดว่าจะตัดสินใจ | เมื่อทราบ | ปรับได้พร้อมเหตุผลเมื่อกำหนดเปลี่ยน |
| เอกสารและกิจกรรม | ระหว่างดำเนินงาน | ลิงก์เอกสาร เวอร์ชัน บันทึกประชุม และข้อตกลง |
| เหตุผลและวันที่เปลี่ยน Status | เปลี่ยน Status | เพิ่มหลักฐานเมื่อ Won และเหตุผลเมื่อ On hold / Lost |
| ประวัติการแก้ไข | ทุกการเปลี่ยนแปลงสำคัญ | ผู้เปลี่ยน เวลา ค่าก่อน/หลัง และเหตุผล |

## Use cases และเงื่อนไขเปลี่ยน Stage

Opportunity owner รับผิดชอบตรวจความพร้อมและบันทึกการเปลี่ยนขั้นตอน โดยให้ผู้เกี่ยวข้องช่วยยืนยันข้อมูลตามตาราง

| การเปลี่ยน | Use case และข้อมูลที่ต้องพร้อม | ผู้เกี่ยวข้อง |
| --- | --- | --- |
| เริ่ม Lead / Opportunity | ตรวจลูกค้าซ้ำ สร้างงาน บันทึกความต้องการ เจ้าของงาน และกิจกรรมถัดไป | Sales / Account owner |
| Lead / Opportunity → Discovery | มีผู้ติดต่อ ความต้องการเบื้องต้น และนัดหรือแนวทางเก็บข้อมูลเพิ่มเติม | Sales และผู้ติดต่อของลูกค้า |
| Discovery → Proposal & Estimate | มีปัญหา เป้าหมาย ผลสำเร็จที่คาดหวัง ขอบเขตเบื้องต้น ระบบเดิม ข้อจำกัด และสมมติฐานเพียงพอให้ประเมินงานได้ | Sales และผู้ประเมินงาน |
| Proposal & Estimate → Decision | ข้อเสนอผ่านการตรวจทานภายในและส่งลูกค้าแล้ว ระบุเวอร์ชัน ขอบเขต สิ่งส่งมอบ ราคา สกุลเงิน ระยะเวลา สมมติฐาน ข้อยกเว้น และวันติดตาม | Sales ผู้ประเมินงาน และผู้ตรวจทานข้อเสนอ |
| Decision + Open → Won | มีหลักฐานลูกค้ายอมรับข้อเสนอ ระบุเวอร์ชันและเงื่อนไขที่ตกลง พร้อมผู้รับผิดชอบส่งต่อ Contract / SOW | Sales และผู้รับช่วงจัดทำ Contract / SOW |

งบประมาณหรือวันตัดสินใจที่ยังไม่ทราบไม่จำเป็นต้องขวางการเปลี่ยนขั้นตอน แต่ต้องบันทึกเป็นประเด็นติดตาม หากข้อมูลขาดจนประเมินไม่ได้ ให้เก็บข้อมูลเพิ่มก่อนเสนอราคา

## กติกาเปลี่ยน Status และกรณีย้อนกลับ

| เหตุการณ์ | การจัดการ |
| --- | --- |
| Open → On hold | คง Stage เดิม ระบุเหตุผล ผู้รับผิดชอบ และวันติดตามใหม่ |
| On hold → Open | คง Stage เดิม บันทึกเหตุผลที่กลับมาดำเนินงาน และกิจกรรมถัดไป |
| Open / On hold → Lost | คง Stage ที่หยุดงาน ระบุเหตุผลและวันที่ปิด เช่น ลูกค้าไม่ดำเนินการหรือเลือกผู้เสนอรายอื่น |
| ต้องค้นหาความต้องการหรือแก้ข้อเสนอเพิ่ม | ย้อน Stage ได้โดยระบุเหตุผล ปรับกิจกรรมถัดไป และเก็บประวัติข้อเสนอเดิม |
| งาน Lost กลับมาพิจารณา | เจ้าของงานเปิดเป็น Open พร้อมเหตุผลและ Stage ที่เหมาะสม หากเป็นขอบเขตใหม่ให้สร้าง Opportunity ใหม่และเชื่อมงานเดิม |
| งาน Won ต้องแก้ผลการขาย | ให้เจ้าของงานและผู้รับช่วงตรวจผลกระทบก่อนเปลี่ยน บันทึกเหตุผลและคงหลักฐานเดิม หากมีสัญญาหรือเริ่มงานแล้วให้จัดการผ่านกระบวนการเปลี่ยนแปลงของงานนั้นด้วย |
| ต้องข้าม Stage | ทำได้เมื่อมีข้อมูลครบตามขั้นตอนที่ข้าม พร้อมบันทึกเหตุผล |

การเปลี่ยน Stage ไม่ทำให้ Status เปลี่ยนอัตโนมัติ ยกเว้นการปิด Won ซึ่งต้องอยู่ที่ Decision ห้ามล้างประวัติเมื่อย้อนขั้นตอนหรือเปิดงานใหม่

## ข้อมูลส่งต่อเมื่อ Won

- Customer และผู้ติดต่อ พร้อมบทบาทของผู้ตัดสินใจและผู้ประสานงาน
- ข้อเสนอฉบับที่ลูกค้ายอมรับ พร้อมเวอร์ชัน วันที่ และหลักฐานอ้างอิง
- ขอบเขต สิ่งส่งมอบ สิ่งที่ไม่รวม สมมติฐาน และเกณฑ์ความสำเร็จที่ตกลง
- ราคา สกุลเงิน กรอบเวลา และเงื่อนไขที่ตกลงหรือยังต้องยืนยัน
- ข้อผูกพันที่แจ้งลูกค้า ความเสี่ยง และประเด็นค้าง พร้อมผู้รับผิดชอบ
- ผู้ส่งต่อ ผู้รับช่วง วันที่ส่งต่อ และสถานะการรับมอบข้อมูล

Won กับการรับมอบข้อมูลเป็นคนละเหตุการณ์ ต้องติดตามให้ผู้รับช่วงยืนยันว่าข้อมูลพร้อมสำหรับ Contract / SOW

## ตัวอย่างการใช้งาน

| เหตุการณ์ | Stage | Status | สิ่งที่บันทึกเพิ่มเติม |
| --- | --- | --- | --- |
| รับงาน `[OPP-001]` จาก `[CUSTOMER-001]` | Lead / Opportunity | Open | ความต้องการ เจ้าของงาน และนัดติดตาม |
| เริ่มสัมภาษณ์ผู้เกี่ยวข้อง | Discovery | Open | ปัญหา เป้าหมาย ระบบเดิม และขอบเขต |
| เริ่มประเมินและจัดทำข้อเสนอ | Proposal & Estimate | Open | ราคา ระยะเวลา และสมมติฐาน |
| ลูกค้าขอพักการพิจารณา | Proposal & Estimate | On hold | เหตุผลและวันติดตามใหม่ |
| ลูกค้ากลับมาหารือ | Proposal & Estimate | Open | ข้อมูลที่เปลี่ยนและกิจกรรมถัดไป |
| ส่งข้อเสนอที่ตรวจทานแล้ว | Decision | Open | เวอร์ชันข้อเสนอและวันติดตามผล |
| ลูกค้ายอมรับข้อเสนอ | Decision | Won | หลักฐานและชุดข้อมูลส่งต่อ Contract / SOW |
