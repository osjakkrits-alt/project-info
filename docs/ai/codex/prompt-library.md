# Codex Prompt Library

Choose the smallest template matching the task, then replace all angle-bracket placeholders.

| Template | Use it for |
| --- | --- |
| `templates/implement-sprint.md` | Delivering a bounded sprint item or feature |
| `templates/resolve-github-issue.md` | Fixing or implementing one GitHub issue |
| `templates/review-implementation.md` | Reviewing a diff for correctness and risk |
| `templates/run-validation.md` | Running and reporting repository checks |

## Custom prompt checklist

- Objective and user-visible outcome
- Scope and excluded areas
- Acceptance criteria
- Relevant files and repository instructions
- Validation commands or discovery requirement
- Required documentation updates
- Expected handoff format
