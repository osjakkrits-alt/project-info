# Codex Prompt Templates

Copy the closest template into a Codex request and replace all `<placeholders>`. Remove sections that do not apply, but retain scope, acceptance criteria, validation, and handoff expectations.

## Templates

- `implement-sprint.md`: implement a bounded sprint item.
- `resolve-github-issue.md`: address one GitHub issue.
- `review-implementation.md`: review an existing implementation without changing it.
- `run-validation.md`: discover, run, and report project checks.

Do not paste secrets or sensitive production data into prompts.
