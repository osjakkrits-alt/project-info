## Instructions

Inspect the issue context, repository instructions, relevant code, and tests. Confirm the cause before editing, implement the smallest complete fix, add proportionate tests, and run applicable validation.

## Handoff

Explain the cause and fix, list changed areas, report validation results and blocked checks, and note any follow-up work. Do not commit, push, or close the issue unless explicitly requested.
